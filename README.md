# MovieStory

This repository collects the source code, scripts, configuration, documentation,
and lightweight example assets used by the MovieStory project.

## Repository layout

- `MovieStory/` — project training, inference, analysis, and design files.
- `Qwen3-VL/` — Qwen3-VL integration and MetaQuery-related code.
- `Wan2.2/` — Wan2.2 integration, training, and inference code.

## Large artifacts

Model weights, checkpoints, optimizer states, downloaded base models, generated
outputs, logs, caches, virtual environments, and temporary data are intentionally
excluded from Git. The uploaded snapshot also excludes individual files of 50 MiB
or more. These artifacts should be downloaded or generated locally as needed.
