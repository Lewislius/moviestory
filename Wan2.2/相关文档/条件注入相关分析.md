## 整体架构概览

Wan2.2 Animate系统通过DiT (Diffusion Transformer) 架构实现视频生成，支持两种主要模式：
- **Animation模式**: 驱动角色动画
- **Replacement模式**: 角色替换（环境保留）

### 核心组件
```
WanAnimateModel (DiT)
├── Patch Embedding (输入编码)
├── Text Embedding (文本条件)
├── Time Embedding (时间步条件)
├── Motion Encoder (动作编码)
├── Face Encoder (面部编码)
├── Face Adapter (面部条件注入)
└── Transformer Blocks (条件融合)
```

def prepare_source(self, src_pose_path, src_face_path, src_ref_path):
    # 读取姿态视频
    pose_video_reader = VideoReader(src_pose_path)
    pose_len = len(pose_video_reader)
    pose_idxs = list(range(pose_len))
    cond_images = pose_video_reader.get_batch(pose_idxs).asnumpy()  # [T, H, W, 3]

    # 读取面部视频
    face_video_reader = VideoReader(src_face_path)
    face_len = len(face_video_reader)
    face_idxs = list(range(face_len))
    face_images = face_video_reader.get_batch(face_idxs).asnumpy()  # [T, H, W, 3]
    
    # 读取参考图像并resize
    height, width = cond_images[0].shape[:2]
    refer_images = cv2.imread(src_ref_path)[..., ::-1]  # BGR->RGB
    refer_images = self.padding_resize(refer_images, height=height, width=width)
    
    return cond_images, face_images, refer_images  # [H, W, 3]
```

- `cond_images`: `[T, H, W, 3]` - T帧姿态图像
- `face_images`: `[T, H, W, 3]` - T帧面部图像  
- `refer_images`: `[H, W, 3]` - 单张参考图像

class MLPProj(torch.nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.proj = torch.nn.Sequential(
            torch.nn.LayerNorm(in_dim),        # 1280
            torch.nn.Linear(in_dim, in_dim),   # 1280 -> 1280
            torch.nn.GELU(),
            torch.nn.Linear(in_dim, out_dim),  # 1280 -> 5120
            torch.nn.LayerNorm(out_dim),       # 5120
        )
    
    def forward(self, image_embeds):
        return self.proj(image_embeds)  # [B, 257, 1280] -> [B, 257, 5120]

# 在模型初始化时
self.img_emb = MLPProj(1280, dim)  # dim=5120

```

- CLIP输出: `[B, 257, 1280]`

  - 1280维CLIP特征
- DiT映射后: `[B, 257, 5120]`

**VAE编码实现**:
```python
# 文件: wan/modules/vae2_1.py (简化版)
class Wan2_1_VAE:
    def __init__(self, vae_pth, device):
        self.vae = AutoencoderKLCausal3D.from_pretrained(vae_pth).to(device)
        self.vae_stride = (4, 8, 8)  # (T, H, W)的下采样倍数
    
    def encode(self, pixel_values):
        # pixel_values: List[Tensor] 或 Tensor
        # 输入: [B, 3, T, H, W] = [1, 3, 77, 512, 512]
        
        with torch.no_grad():
            if isinstance(pixel_values, list):
                latents = []
                for pv in pixel_values:
                    # VAE编码
                    dist = self.vae.encode(pv.unsqueeze(0)).latent_dist
                    latent = dist.sample() * self.vae.config.scaling_factor
                    latents.append(latent[0])  # [16, lat_t, lat_h, lat_w]
                return latents
            else:
                dist = self.vae.encode(pixel_values).latent_dist
                return dist.sample() * self.vae.config.scaling_factor
        
        # 输出维度计算:
        # lat_t = T // vae_stride[0] + 1 = 77 // 4 + 1 = 20
        # lat_h = H // vae_stride[1] = 512 // 8 = 64
        # lat_w = W // vae_stride[2] = 512 // 8 = 64
        # 输出: [16, 20, 64, 64]
```

**Pose Patch Embedding**:

# Forward处理 (wan/modules/animate/model_animate.py, 行: 346-349)
def after_patch_embedding(self, x, pose_latents, face_pixel_values):
    # x: List[Tensor], 每个Tensor shape为 [1, 5120, lat_t, lat_h//2, lat_w//2]
    # pose_latents: List[Tensor], 每个shape为 [1, 16, lat_t-1, lat_h, lat_w]
    
    # 对每个pose_latents进行patch embedding
    pose_latents = [
        self.pose_patch_embedding(u.unsqueeze(0))  # [1,16,20,64,64] -> [1,5120,20,32,32]
        for u in pose_latents
    ]
    
    # 叠加到主特征上 (除第一帧外)
    for x_, pose_latents_ in zip(x, pose_latents):
        # x_: [1, 5120, 21, 32, 32]  (21 = lat_t + 1，包含参考帧)
        # pose_latents_: [1, 5120, 20, 32, 32]
        x_[:, :, 1:] += pose_latents_  # 第0帧是参考帧，不加pose
    
    return x, motion_vec
```

**维度变化总结**:
- 输入视频: `[1, 3, 77, 512, 512]`
- VAE编码: `[1, 16, 20, 64, 64]`
  - 通道: 3 → 16 (潜在空间)
  - 时间: 77 → 20 (下采样4倍+1)
  - 空间: 512 → 64 (下采样8倍)
- Pose Patch: `[1, 5120, 20, 32, 32]`
  - 通道: 16 → 5120 (特征维度)
  - 空间: 64 → 32 (patch size=2)
- 叠加后: 与主特征相加，保持 `[1, 5120, 21, 32, 32]`

**1. Motion Encoder (StyleGAN-based)**:
```python
# 文件: wan/modules/animate/motion_encoder.py, 行: 200-307
class Generator(nn.Module):
    def __init__(self, size=512, style_dim=512, motion_dim=20):
        super().__init__()
        # Encoder部分 (提取特征)
        self.encoder = nn.ModuleList([
            ConvLayer(3, 64, 3),
            ResBlock(64, 128),
            ResBlock(128, 256),
            ResBlock(256, 512),
            ResBlock(512, 512),
        ])
        
        # Motion特征提取
        self.motion_encoder = nn.Sequential(
            nn.Linear(512 * 16 * 16, 1024),  # Flatten后的特征
            nn.ReLU(),
            nn.Linear(1024, motion_dim)       # 20维motion向量
        )
        
        # 扩展到style_dim
        self.motion_proj = nn.Linear(motion_dim, style_dim)  # 20 -> 512
    
    def get_motion(self, x):
        # x: [(B*T), 3, 512, 512] - 批量面部图像
        
        # 编码特征
        for block in self.encoder:
            x = block(x)  # -> [(B*T), 512, 16, 16]
        
        # 提取motion向量
        feat = x.view(x.size(0), -1)  # [(B*T), 512*16*16]
        motion = self.motion_encoder(feat)  # [(B*T), 20]
        motion = self.motion_proj(motion)    # [(B*T), 512]
        
        return motion  # [(B*T), 512]

# 在after_patch_embedding中调用 (wan/modules/animate/model_animate.py, 行: 351-357)
b, c, T, h, w = face_pixel_values.shape  # [1, 3, 77, 512, 512]

**2. Face Encoder (时序处理)**:
```python
# 文件: wan/modules/animate/face_blocks.py, 行: 134-175
class FaceEncoder(nn.Module):
    def __init__(self, in_dim=512, hidden_dim=5120, num_heads=4, dtype=None, device=None):
        super().__init__()
        self.num_heads = num_heads  # 4
        
        # 第一层卷积: 扩展维度并分多头
        self.conv1_local = CausalConv1d(
            in_dim,                    # 512
            1024 * num_heads,          # 1024 * 4 = 4096
            kernel_size=3, stride=1
        )
        self.norm1 = nn.LayerNorm(1024, elementwise_affine=False, eps=1e-6)
        self.act = nn.SiLU()
        
        # 时序下采样卷积
        self.conv2 = CausalConv1d(1024, 1024, 3, stride=2)  # T -> T//2
        self.norm2 = nn.LayerNorm(1024, elementwise_affine=False, eps=1e-6)
        
        self.conv3 = CausalConv1d(1024, 1024, 3, stride=2)  # T//2 -> T//4
        self.norm3 = nn.LayerNorm(1024, elementwise_affine=False, eps=1e-6)
        
        # 输出投影到DiT维度
        self.out_proj = nn.Linear(1024, hidden_dim)  # 1024 -> 5120
        
        # Padding token
        self.padding_tokens = nn.Parameter(torch.zeros(1, 1, 1, hidden_dim))
    
    def forward(self, x):
        # x: [B, T, C] = [1, 77, 512]
        
        x = rearrange(x, "b t c -> b c t")  # [1, 512, 77]
        b, c, t = x.shape
        
        # 第一层: 扩展并分多头
        x = self.conv1_local(x)  # [1, 4096, 77]
        x = rearrange(x, "b (n c) t -> (b n) t c", n=self.num_heads)  # [4, 77, 1024]
        x = self.norm1(x)
        x = self.act(x)
        
        # 时序下采样1
        x = rearrange(x, "b t c -> b c t")  # [4, 1024, 77]
        x = self.conv2(x)  # [4, 1024, 39] (stride=2)
        x = rearrange(x, "b c t -> b t c")  # [4, 39, 1024]
        x = self.norm2(x)
        x = self.act(x)
        
        # 时序下采样2
        x = rearrange(x, "b t c -> b c t")  # [4, 1024, 39]
        x = self.conv3(x)  # [4, 1024, 20] (stride=2)
        x = rearrange(x, "b c t -> b t c")  # [4, 20, 1024]
        x = self.norm3(x)
        x = self.act(x)
        
        # 输出投影
        x = self.out_proj(x)  # [4, 20, 5120]
        x = rearrange(x, "(b n) t c -> b t n c", b=b)  # [1, 20, 4, 5120]
        
        # 添加padding token (第5个head)
        padding = self.padding_tokens.repeat(b, x.shape[1], 1, 1)  # [1, 20, 1, 5120]
        x = torch.cat([x, padding], dim=-2)  # [1, 20, 5, 5120]
        
        return x

# 最后添加时间维度的padding (wan/modules/animate/model_animate.py, 行: 359-361)
B, L, H, C = motion_vec.shape  # [1, 20, 5, 5120]
pad_face = torch.zeros(B, 1, H, C).type_as(motion_vec)  # [1, 1, 5, 5120]
motion_vec = torch.cat([pad_face, motion_vec], dim=1)  # [1, 21, 5, 5120]
```

**维度变化总结**:
- 输入面部视频: `[1, 3, 77, 512, 512]`
- Motion Encoder: `[77, 512]` (每帧一个512维向量)
- Face Encoder:
  - Conv1: `[4, 77, 1024]` (分4个头)
  - Conv2: `[4, 39, 1024]` (时序降采样)
  - Conv3: `[4, 20, 1024]` (再次降采样)
  - OutProj: `[1, 20, 4, 5120]` (投影到DiT维度)
  - +Padding: `[1, 20, 5, 5120]` (添加第5个头)
  - +TimePad: `[1, 21, 5, 5120]` (添加时间padding)
- 最终输出: `[B, 21, 5, 5120]`

**get_i2v_mask详细实现**:
```python
# 文件: wan/animate.py, 行: 233-240
def get_i2v_mask(self, lat_t, lat_h, lat_w, mask_len=1, 
                 mask_pixel_values=None, device="cuda"):
    """
    生成图像到视频的mask
    
    Args:
        lat_t: latent时间维度 (如20)
        lat_h, lat_w: latent空间维度 (如64, 64)
        mask_len: 标记为参考帧的数量 (如1或5)
        mask_pixel_values: 自定义mask [B, T, H, W] (用于Replacement模式)
    
    Returns:
        mask: [4, lat_t, lat_h, lat_w] - 4通道mask
    """
    # 创建或使用提供的mask
    if mask_pixel_values is None:
        # 默认全0 mask
        msk = torch.zeros(1, (lat_t-1)*4+1, lat_h, lat_w, device=device)
        # (lat_t-1)*4+1 是因为需要从latent空间映射回像素空间的帧数
        # 例如: lat_t=20 -> (20-1)*4+1 = 77帧
    else:
        # 使用提供的mask (Replacement模式)
        msk = mask_pixel_values.clone()  # [1, T, H, W]
    
    # 标记前mask_len帧为1 (表示这些帧是参考帧/已知帧)
    msk[:, :mask_len] = 1
    
    # 时间维度处理: 第一帧重复4次,后续帧保持
    # 这是为了匹配VAE的时间下采样 (4倍)
    msk = torch.concat([
        torch.repeat_interleave(msk[:, 0:1], repeats=4, dim=1),  # 第1帧重复4次
        msk[:, 1:]  # 剩余帧
    ], dim=1)
    
    # 重组为latent时间维度
    msk = msk.view(1, msk.shape[1]//4, 4, lat_h, lat_w)  # [1, lat_t, 4, H, W]
    msk = msk.transpose(1, 2)[0]  # [4, lat_t, H, W]
    
    return msk
```

**维度**:
- `ref_latents`: `[1, 16, 1, lat_h, lat_w]` = `[1, 16, 1, 64, 64]`
- `mask_ref`: `[4, 1, lat_h, lat_w]` = `[4, 1, 64, 64]` (mask通道)
- `y_ref`: `[20, 1, 64, 64]` (16+4=20通道)

def get_i2v_mask(self, lat_t, lat_h, lat_w, mask_len=1, 
                 mask_pixel_values=None, device="cuda"):
    if mask_pixel_values is None:
        msk = torch.zeros(1, (lat_t-1)*4+1, lat_h, lat_w, device=device)
    else:
        msk = mask_pixel_values.clone()  # 使用提供的mask
    msk[:, :mask_len] = 1  # 前mask_len帧设为1
    # 时间维度插值到4倍
    msk = torch.concat([
        torch.repeat_interleave(msk[:, 0:1], repeats=4, dim=1), 
        msk[:, 1:]
    ], dim=1)
    msk = msk.view(1, msk.shape[1]//4, 4, lat_h, lat_w)
    msk = msk.transpose(1, 2)[0]
    return msk

```python
# 文件: wan/modules/animate/model_animate.py, 行: 368-435
def forward(
    self,
    x,                    # List[Tensor]: 噪声latent, 每个shape [16, lat_t, lat_h, lat_w]
    t,                    # Tensor: 时间步 [B]
    clip_fea,            # Tensor: CLIP特征 [B, 257, 1280]
    context,             # List[Tensor]: 文本特征, 每个shape [512, 4096]
    seq_len,             # int: 最大序列长度 (21504)
    y=None,              # List[Tensor]: 条件y, 每个shape [20, lat_t+1, lat_h, lat_w]
    pose_latents=None,   # List[Tensor]: 姿态latent
    face_pixel_values=None  # Tensor: 面部图像 [B, 3, T, 512, 512]
):
    """DiT模型的前向传播"""
    
    # ========== Step 1: 输入准备 ==========
    device = self.patch_embedding.weight.device
    if self.freqs.device != device:
        self.freqs = self.freqs.to(device)  # RoPE频率
    
    # 合并条件y (如果使用CFG)
    if y is not None:
        # x: [16, lat_t, lat_h, lat_w]
        # y: [20, lat_t+1, lat_h, lat_w]
        x = [torch.cat([u, v], dim=0) for u, v in zip(x, y)]
        # 合并后: [36, lat_t+1, lat_h, lat_w]  (36=16+20通道)
    
    # ========== Step 2: Patch Embedding ==========
    # 输入: [36, 21, 64, 64] -> 输出: [1, 5120, 21, 32, 32]
    x = [self.patch_embedding(u.unsqueeze(0)) for u in x]
    
    # ========== Step 3: 姿态条件注入 ==========
    x, motion_vec = self.after_patch_embedding(x, pose_latents, face_pixel_values)
    # x: [1, 5120, 21, 32, 32] (已加上pose)
    # motion_vec: [B, 21, 5, 5120] (面部特征)
    
    # ========== Step 4: Flatten与Padding ==========
    # 计算grid sizes
    grid_sizes = torch.stack([
        torch.tensor(u.shape[2:], dtype=torch.long) 
        for u in x
    ])  # [B, 3] = [[21, 32, 32]]
    
    # Flatten: [1, 5120, 21, 32, 32] -> [1, 21*32*32, 5120] = [1, 21504, 5120]
    x = [u.flatten(2).transpose(1, 2) for u in x]
    
    # 记录每个序列的实际长度
    seq_lens = torch.tensor([u.size(1) for u in x], dtype=torch.long)  # [21504]
    
    # Padding到统一长度 (如果需要)
    assert seq_lens.max() <= seq_len
    x = torch.cat([
        torch.cat([u, u.new_zeros(1, seq_len-u.size(1), u.size(2))], dim=1) 
        for u in x
    ])  # [B, seq_len, 5120]
    
    # ========== Step 5: 时间步编码 ==========
    with amp.autocast(dtype=torch.float32):
        # Sinusoidal embedding
        t_emb = sinusoidal_embedding_1d(self.freq_dim, t).float()  # [B, 256]
        
        # MLP projection
        e = self.time_embedding(t_emb)  # [B, 256] -> [B, 5120]
        
        # 生成6个modulation参数
        e0 = self.time_projection(e).unflatten(1, (6, self.dim))  # [B, 6, 5120]
        assert e.dtype == torch.float32 and e0.dtype == torch.float32
    
    # ========== Step 6: 文本+CLIP条件准备 ==========
    context_lens = None
    
    # 文本embedding
    context = self.text_embedding(
        torch.stack([
            torch.cat([u, u.new_zeros(self.text_len-u.size(0), u.size(1))])
            for u in context
        ])  # Padding到text_len=512
    )  # [B, 512, 4096] -> [B, 512, 5120]
    
    # 拼接CLIP特征
    if self.use_img_emb:
        context_clip = self.img_emb(clip_fea)  # [B, 257, 1280] -> [B, 257, 5120]
        context = torch.concat([context_clip, context], dim=1)  # [B, 769, 5120]
    
    # ========== Step 7: Transformer处理 ==========
    # 准备参数
    kwargs = dict(
        e=e0,                    # [B, 6, 5120] - modulation参数
        seq_lens=seq_lens,       # [B] - 序列长度
        grid_sizes=grid_sizes,   # [B, 3] - 空间尺寸
        freqs=self.freqs,        # [1024, 128] - RoPE频率
        context=context,         # [B, 769, 5120] - 文本+CLIP
        context_lens=context_lens  # None
    )
    
    # Sequence Parallel (如果启用)
    if self.use_context_parallel:
        x = torch.chunk(x, get_world_size(), dim=1)[get_rank()]
    
    # 逐层处理
    for idx, block in enumerate(self.blocks):
        # Self-Attention + Cross-Attention + FFN
        x = block(x, **kwargs)  # [B, seq_len, 5120]
        
        # 每5层注入面部条件
        x = self.after_transformer_block(idx, x, motion_vec)  # +Face Adapter
    
    # ========== Step 8: 输出Head ==========
    x = self.head(x, e)  # [B, seq_len, 5120] -> [B, seq_len, 16]
    
    if self.use_context_parallel:
        x = gather_forward(x, dim=1)
    
    # ========== Step 9: Unpatchify ==========
    x = self.unpatchify(x, grid_sizes)  # [B, seq_len, 16] -> [16, lat_t, lat_h, lat_w]
    
    return [u.float() for u in x]  # 返回List[Tensor]
```

# 文件: wan/modules/animate/model_animate.py, 行: 147-226
class WanAnimateAttentionBlock(nn.Module):
    def __init__(self, dim, ffn_dim, num_heads, window_size=(-1,-1),
                 qk_norm=True, cross_attn_norm=True, eps=1e-6, use_img_emb=True):
        super().__init__()
        self.dim = dim              # 5120
        self.ffn_dim = ffn_dim      # 13824
        self.num_heads = num_heads  # 40
        
        # Layers
        self.norm1 = WanLayerNorm(dim, eps)
        self.self_attn = WanAnimateSelfAttention(
            dim, num_heads, window_size, qk_norm, eps
        )
        
        self.norm3 = WanLayerNorm(dim, eps, elementwise_affine=True) \
            if cross_attn_norm else nn.Identity()
        self.cross_attn = WanAnimateCrossAttention(
            dim, num_heads, (-1,-1), qk_norm, eps, use_img_emb=use_img_emb
        )
        
        self.norm2 = WanLayerNorm(dim, eps)
        self.ffn = nn.Sequential(
            nn.Linear(dim, ffn_dim),        # 5120 -> 13824
            nn.GELU(approximate='tanh'),
            nn.Linear(ffn_dim, dim)         # 13824 -> 5120
        )
        
        # Modulation参数 (可学习)
        self.modulation = nn.Parameter(torch.randn(1, 6, dim) / dim**0.5)
    
    def forward(
        self,
        x,            # [B, seq_len, C] - 输入特征
        e,            # [B, 6, C] - 时间步modulation参数
        seq_lens,     # [B] - 序列长度
        grid_sizes,   # [B, 3] - 空间尺寸 (F,H,W)
        freqs,        # [1024, C/num_heads/2] - RoPE频率
        context,      # [B, context_len, C] - 文本+CLIP条件
        context_lens, # None或[B] - context长度
    ):
        """
        Transformer Block处理
        
        处理流程:
        1. Self-Attention (with RoPE + Modulation)
        2. Cross-Attention (to Text+CLIP)
        3. FFN (with Modulation)
        """
        
        # ========== Modulation参数准备 ==========
        assert e.dtype == torch.float32
        with amp.autocast(dtype=torch.float32):
            # e: [B, 6, C] + modulation: [1, 6, C]
            e = (self.modulation + e).chunk(6, dim=1)  # 分成6个: e[0]~e[5]
        assert e[0].dtype == torch.float32
        # e[0], e[1]: Self-Attn的shift和scale
        # e[2]: Self-Attn的gate
        # e[3], e[4]: FFN的shift和scale
        # e[5]: FFN的gate
        
        # ========== Self-Attention ==========
        # 1. 输入modulation: scale & shift
        x_norm = self.norm1(x).float()  # [B, seq_len, C]
        x_modulated = x_norm * (1 + e[1]) + e[0]  # affine transformation
        
        # 2. Self-Attention (with RoPE)
        y = self.self_attn(
            x_modulated, 
            seq_lens,      # 用于mask
            grid_sizes,    # 用于RoPE的3D位置
            freqs          # RoPE频率
        )  # [B, seq_len, C]
        
        # 3. 输出modulation: gate
        with amp.autocast(dtype=torch.float32):
            x = x + y * e[2]  # 门控残差连接
        
        # ========== Cross-Attention ==========
        x = x + self.cross_attn(
            self.norm3(x),     # Query from video features
            context,           # Key,Value from text+CLIP
            context_lens       # context mask (None表示全部attend)
        )
        
        # ========== FFN ==========
        # 1. 输入modulation
        x_norm = self.norm2(x).float()
        x_modulated = x_norm * (1 + e[4]) + e[3]
        
        # 2. Feed-Forward Network
        y = self.ffn(x_modulated)  # [B, seq_len, C] -> [B, seq_len, C]
        
        # 3. 输出modulation
        with amp.autocast(dtype=torch.float32):
            x = x + y * e[5]
        
        return x  # [B, seq_len, C]
```

**Modulation机制详解**:
```python
# 时间步编码生成6个参数
e0 = time_projection(time_embedding(t))  # [B, 6, 5120]

# 在每层加上可学习的modulation bias
e_total = modulation + e0  # [B, 6, 5120]

# 分配给不同位置
shift1, scale1, gate1, shift2, scale2, gate2 = e_total.chunk(6, dim=1)

# Self-Attention:
#   输入: x_norm * (1 + scale1) + shift1
#   输出: x + attn_out * gate1

# FFN:
#   输入: x_norm * (1 + scale2) + shift2
#   输出: x + ffn_out * gate2
```

# 文件: wan/modules/animate/model_animate.py, 行: 90-145
class WanAnimateCrossAttention(WanSelfAttention):
    def __init__(self, dim, num_heads, window_size=(-1,-1), 
                 qk_norm=True, eps=1e-6, use_img_emb=True):
        super().__init__(dim, num_heads, window_size, qk_norm, eps)
        self.use_img_emb = use_img_emb

        if use_img_emb:
            # CLIP特征的单独K,V映射
            self.k_img = nn.Linear(dim, dim)
            self.v_img = nn.Linear(dim, dim)
            self.norm_k_img = WanRMSNorm(dim, eps=eps) if qk_norm else nn.Identity()

    def forward(self, x, context, context_lens):
        # x:       [B, L1, C] - 视频特征 (Query)
        # context: [B, L2, C] - 文本+CLIP特征 (Key, Value)
        
        if self.use_img_emb:
            context_img = context[:, :257]    # 前257个: CLIP特征
            context = context[:, 257:]         # 后512个: 文本特征
        
        b, n, d = x.size(0), self.num_heads, self.head_dim
        
        # ========== 文本路径 ==========
        # 计算Q, K, V
        q = self.norm_q(self.q(x)).view(b, -1, n, d)        # [B, L1, 40, 128]
        k = self.norm_k(self.k(context)).view(b, -1, n, d)  # [B, 512, 40, 128]
        v = self.v(context).view(b, -1, n, d)               # [B, 512, 40, 128]
        
        # Attention计算
        x = flash_attention(q, k, v, k_lens=context_lens)  # [B, L1, 40, 128]
        
        # ========== CLIP路径 (如果启用) ==========
        if self.use_img_emb:
            k_img = self.norm_k_img(self.k_img(context_img)).view(b, -1, n, d)  # [B, 257, 40, 128]
            v_img = self.v_img(context_img).view(b, -1, n, d)                   # [B, 257, 40, 128]
            img_x = flash_attention(q, k_img, v_img, k_lens=None)               # [B, L1, 40, 128]
            
            # 两路相加融合
            x = x.flatten(2) + img_x.flatten(2)  # [B, L1, 5120]
        else:
            x = x.flatten(2)
        
        # 输出投影
        x = self.o(x)  # [B, L1, 5120]
        return x
```

- 两路结果相加融合

```python
# 文件: wan/modules/animate/face_blocks.py, 行: 262-383
class FaceBlock(nn.Module):
    def __init__(self, hidden_size=5120, heads_num=40, qk_norm=True, 
                 qk_norm_type="rms", qk_scale=None, dtype=None, device=None):
        super().__init__()
        self.hidden_size = hidden_size  # 5120
        self.heads_num = heads_num      # 40
        head_dim = hidden_size // heads_num  # 128
        self.scale = qk_scale or head_dim**-0.5
       
        # Linear层
        self.linear1_kv = nn.Linear(hidden_size, hidden_size * 2)  # K,V映射
        self.linear1_q = nn.Linear(hidden_size, hidden_size)       # Q映射
        self.linear2 = nn.Linear(hidden_size, hidden_size)         # 输出投影
        
        # QK Normalization
        qk_norm_layer = RMSNorm if qk_norm_type == "rms" else nn.LayerNorm
        self.q_norm = qk_norm_layer(head_dim, elementwise_affine=True, eps=1e-6) \
            if qk_norm else nn.Identity()
        self.k_norm = qk_norm_layer(head_dim, elementwise_affine=True, eps=1e-6) \
            if qk_norm else nn.Identity()
        
        # Layer Normalization
        self.pre_norm_feat = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
        self.pre_norm_motion = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
    
    def forward(
        self,
        x: torch.Tensor,           # [B, seq_len, C] - DiT特征
        motion_vec: torch.Tensor,  # [B, T, N, C] - 面部特征
        motion_mask: Optional[torch.Tensor] = None,
        use_context_parallel=False,
    ) -> torch.Tensor:
        """
        Face Adapter的核心：用面部特征作为K,V，DiT特征作为Q
        实现面部表情/动作的精细控制
        """
        
        B, T, N, C = motion_vec.shape  # [1, 21, 5, 5120]
        T_comp = T  # 21
        
        # ========== 归一化 ==========
        x_feat = self.pre_norm_feat(x)        # [B, seq_len, 5120]
        x_motion = self.pre_norm_motion(motion_vec)  # [B, 21, 5, 5120]
        
        # ========== 计算QKV ==========
        # Query: 从DiT特征生成
        q = self.linear1_q(x_feat)  # [B, seq_len, 5120]
        q = rearrange(q, "B S (H D) -> B S H D", H=self.heads_num)  # [B, seq_len, 40, 128]
        
        # Key, Value: 从面部特征生成
        kv = self.linear1_kv(x_motion)  # [B, 21, 5, 10240]
        k, v = rearrange(kv, "B L N (K H D) -> K B L N H D", 
                        K=2, H=self.heads_num)  
        # k: [B, 21, 5, 40, 128]
        # v: [B, 21, 5, 40, 128]
        
        # ========== QK Normalization ==========
        q = self.q_norm(q).to(v)  # [B, seq_len, 40, 128]
        k = self.k_norm(k).to(v)  # [B, 21, 5, 40, 128]
        
        # ========== 重排用于Attention ==========
        # 每个时间帧的特征独立处理
        k = rearrange(k, "B L N H D -> (B L) N H D")  # [B*21, 5, 40, 128]
        v = rearrange(v, "B L N H D -> (B L) N H D")  # [B*21, 5, 40, 128]
        
        # Sequence Parallel处理
        if use_context_parallel:
            q = gather_forward(q, dim=1)
        
        # 按时间分组Query
        q = rearrange(q, "B (L S) H D -> (B L) S H D", L=T_comp)  
        # [B*21, seq_len//21, 40, 128]
        
        # ========== Attention计算 ==========
        # 每一帧的空间token查询对应帧的面部特征
        attn = attention(
            q,  # [B*21, S, 40, 128] - Query: 当前帧的空间token
            k,  # [B*21, 5, 40, 128] - Key: 当前帧的5个面部特征头
            v,  # [B*21, 5, 40, 128] - Value: 当前帧的5个面部特征头
            max_seqlen_q=q.shape[1],
            batch_size=q.shape[0],
        )  # [B*21, S, 5120]
        
        # ========== 重排回原形状 ==========
        attn = rearrange(attn, "(B L) S C -> B (L S) C", L=T_comp)  # [B, seq_len, 5120]
        
        if use_context_parallel:
            attn = torch.chunk(attn, get_world_size(), dim=1)[get_rank()]
        
        # ========== 输出投影 ==========
        output = self.linear2(attn)  # [B, seq_len, 5120]
        
        # ========== 可选的Mask ==========
        if motion_mask is not None:
            output = output * rearrange(motion_mask, "B T H W -> B (T H W)").unsqueeze(-1)
        
        return output  # [B, seq_len, 5120] - 残差输出
```

**注入频率**: 40层中每5层注入一次，共8次 (layer 0,5,10,15,20,25,30,35)

**关键设计**:
1. **Q from DiT**: 视频特征作为查询
2. **K,V from Face**: 面部特征作为键值
3. **时序对齐**: 每帧的空间token查询对应帧的面部特征
4. **多头机制**: 5个头 (4个主要+1个padding)

        # x: [B, seq_len, 5120] - DiT特征
        # motion_vec: [B, 21, 5, 5120] - 面部特征
        
        x_feat = self.pre_norm_feat(x)
        x_motion = self.pre_norm_motion(motion_vec)
        
        # 计算QKV
        q = self.linear1_q(x_feat)  # [B, seq_len, 5120]
        kv = self.linear1_kv(x_motion)  # [B, 21, 5, 10240]
        k, v = rearrange(kv, "B L N (K H D) -> K B L N H D", K=2, H=40)
        
        # Q: DiT特征查询
        # K,V: 面部特征作为键值
        q = rearrange(q, "B S (H D) -> B S H D", H=40)
        q = self.q_norm(q)
        k = self.k_norm(k)
        
        # Attention计算
        k = rearrange(k, "B L N H D -> (B L) N H D")
        v = rearrange(v, "B L N H D -> (B L) N H D")
        q = rearrange(q, "B (L S) H D -> (B L) S H D", L=21)
        
        attn = attention(q, k, v)  # 每帧的特征查询对应的面部特征
        attn = rearrange(attn, "(B L) S C -> B (L S) C", L=21)
        
        output = self.linear2(attn)
        if motion_mask is not None:
            output = output * motion_mask  # 可选的mask控制
        
        return output  # 残差输出
```

**注入频率**: 40层中每5层注入一次，共8次 (layer 0,5,10,15,20,25,30,35)

### 3. 条件融合总结

#### 条件结合方式
| 条件 | 融合方式 | 时机 | 频率 |
|-----|---------|------|------|
| 姿态条件 | **加法** (Addition) | Patch Embedding后 | 1次 |
| 时间步 | **调制** (Modulation) | 每个Block的Norm | 每层 |
| 文本+CLIP | **Cross-Attention** | 每个Block | 每层 |
| 面部条件 | **Cross-Attention + 残差** | Face Adapter | 每5层 |
| 参考帧y | **通道拼接** | 输入阶段 | 1次 |
| 背景+Mask | **通道拼接+Mask引导** | 输入阶段 | 1次 |

#### 信息流图
```
输入噪声 latent [16, 21, 64, 64]
    + 参考条件 y [20, 21, 64, 64]
    ↓ concat
合并latent [36, 21, 64, 64]
    ↓ Patch Embedding
特征 [B, 21504, 5120]
    + Pose Latents (加法)
    ↓
进入Transformer Blocks (40层):
    每层:
        ├─ Time Embedding → Modulation (调制)
        ├─ Self-Attention
        ├─ Cross-Attention ← Text+CLIP条件
        └─ FFN
    每5层:
        └─ Face Adapter ← 面部条件 (残差)
    ↓
输出特征 [B, 21504, 16]
    ↓ Unpatchify
输出latent [16, 21, 64, 64]
    ↓ VAE Decode
生成视频 [3, 77, 512, 512]
```

### 1. Mask的双重作用

#### 作用1: 指导生成区域

- Mask值为1: 保留区域 (背景)

**完整Mask处理代码**:

**get_i2v_mask中的mask处理**:
```python
# 文件: wan/animate.py, 行: 233-240
def get_i2v_mask(self, lat_t, lat_h, lat_w, mask_len=1, 
                 mask_pixel_values=None, device="cuda"):
    if mask_pixel_values is None:
        # Animation模式: 创建全零mask
        msk = torch.zeros(1, (lat_t-1)*4+1, lat_h, lat_w, device=device)
    else:
        # Replacement模式: 使用提供的空间mask
        msk = mask_pixel_values.clone()  # [1, 77, 64, 64]
    
    # 标记前mask_len帧为1 (时序参考帧)
    msk[:, :mask_len] = 1
    
    # 时间维度处理 (映射回latent时间步)
    msk = torch.concat([
        torch.repeat_interleave(msk[:, 0:1], repeats=4, dim=1),
        msk[:, 1:]
    ], dim=1)
    
    # 重组为4通道mask
    msk = msk.view(1, msk.shape[1]//4, 4, lat_h, lat_w)  # [1, 20, 4, 64, 64]
    msk = msk.transpose(1, 2)[0]  # [4, 20, 64, 64]
    
    return msk
```

**Mask的含义**:
- **Animation模式**: 
  - mask只标记时序参考帧位置 (前几帧为1,其余为0)
  - 空间上全为0,表示全部区域都需要生成
  
- **Replacement模式**:
  - mask标记时序参考帧 + 空间保留区域
  - 空间上: 1=保留背景, 0=生成新角色
  - 时间上: 前refert_num帧全为1 (已知帧)

#### 作用2: 潜在空间融合

**完整背景融合代码**:
```python
# 文件: wan/animate.py, 行: 518-571

        mask_pixel_values=mask_pixel_values

**关键流程**:
1. **输入准备**:
   - 已生成帧: 上一clip的最后几帧 (保持连续性)
   - 背景视频: 当前clip的所有帧 (提供环境)
   - Mask: 标记哪些区域是背景

2. **时空融合**:
   - 时间: 前`refert_num`帧用已生成内容,后续用背景
   - 空间: 通过mask在latent空间中标记保留/生成区域

3. **DiT处理**:
   - DiT看到融合后的latent和mask
   - 在mask=1的区域倾向于保留原latent (背景)
   - 在mask=0的区域进行去噪生成 (角色)

**维度总结**:
```

Mask:       [1, 1, 77, H, W]  (二值mask)

↓ VAE编码 + Mask下采样

Mask latent:[4, 20, 64, 64]   (4通道mask)

↓ 拼接

### Classifier-Free Guidance (CFG)详解

**作用**: 增强表情控制

**实现细节**:
```python
# 条件分支 (cond)
noise_cond = DiT(
    latent, t,
    context=positive_prompt,      # "笑脸"
    face=face_features,           # 笑脸特征
    pose=pose,                    # 保持
    y=ref+bg                      # 保持
)

# 无条件分支 (uncond)
noise_uncond = DiT(
    latent, t,
    context=negative_prompt,      # ""或"不好的"
    face=zero_face,               # 全-1 (无面部)
    pose=pose,                    # 保持
    y=ref+bg                      # 保持
)

# CFG公式
noise = uncond + scale * (cond - uncond)
     = uncond * (1 - scale) + cond * scale

# scale=1.0: 纯条件生成 (无CFG)
# scale=1.5: 增强表情控制
# scale>2.0: 可能过度增强,导致失真
```

**关键点**:
1. **仅face条件变化**: 只有面部特征在cond/uncond间变化
2. **其他条件保持**: 姿态、背景、参考帧等都保持一致
3. **性能考虑**: CFG需要2次DiT forward,计算量翻倍

## DiT条件处理与加噪去噪机制详解

### 1. 目标帧与参考帧的关系

#### 1.1 概念定义

**参考帧 (Reference Frame - y)**:
- 已知的、确定的帧内容
- 包括：初始参考图像 + 已生成的前几帧 + 背景(Replacement模式)
- 作用：提供外观、时序和环境的约束条件
- 维度：`[20, lat_t+1, lat_h, lat_w]` = `[20, 21, 64, 64]`

**目标帧 (Target Frame - x)**:
- 待生成的、未知的帧内容
- 初始状态：纯噪声
- 通过去噪过程逐步恢复为清晰图像
- 维度：`[16, lat_t, lat_h, lat_w]` = `[16, 20, 64, 64]`

#### 1.2 关系图示

```
时间轴: t=0     t=1,2,3...refert_num    t=refert_num+1...T
        ↓       ↓                        ↓
参考帧: [初始]  [已生成的前几帧]        [背景或零(待生成)]
        ↓       ↓                        ↓
y:      确定    确定(mask=1)            背景/零
        └────────────┬──────────────┘
                     ↓
目标帧: [---]   [待生成]                [待生成]
        ↓       ↓                        ↓
x:      跳过    从噪声去噪              从噪声去噪
```

**参考帧y的构建**:

### 2. 加噪与去噪机制

#### 2.1 Flow Matching框架

Wan2.2使用的是**Flow Matching**而非传统DDPM，关键区别：

**传统DDPM**:
- 加噪: $x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon$
- 去噪: 学习噪声 $\epsilon_\theta(x_t, t)$

**Flow Matching**:
- 定义ODE流: $\frac{dx_t}{dt} = v_\theta(x_t, t)$
- 直接学习速度场 $v_\theta$
- 噪声→数据: $x_t = t \cdot x_1 + (1-t) \cdot x_0$，其中 $t \in [0,1]$

    x1 = vae.encode(clean_video)  # [16, 21, 64, 64] - 目标(干净)

    t = torch.rand(batch_size)  # 均匀采样
    
    # 3. 采样噪声
    x0 = torch.randn_like(x1)  # [16, 21, 64, 64] - 源(噪声)
    
    # 4. Flow Matching插值
    # 简单线性插值: x_t = (1-t)*x0 + t*x1
    xt = (1 - t.view(-1,1,1,1)) * x0 + t.view(-1,1,1,1) * x1
    
    # 5. 计算目标速度 (从x0到x1的方向)
    target_v = x1 - x0  # 目标速度场
    
    # 6. DiT预测速度
    pred_v = dit_model(xt, t, conditions)  # 预测速度场
    
    # 7. 计算损失
    loss = F.mse_loss(pred_v, target_v)
    
    return loss

# 关键点:
# - 不需要多步加噪，直接一步插值到任意t
# - 学习的是x0→x1的速度场，而非噪声
# - t=0: 纯噪声; t=1: 干净数据
```

# 文件: wan/utils/fm_solvers.py, 行: 20-25
def get_sampling_sigmas(sampling_steps, shift):
    """
    生成采样时间步
    
    Args:
        sampling_steps: 采样步数 (如20)
        shift: 时间步偏移 (如5.0)
    
    Returns:
        sigma: 从1到0的时间步序列
    """
    # 线性分布: [1.0, ..., 0.0]
    sigma = np.linspace(1, 0, sampling_steps + 1)[:sampling_steps]
    
    # 应用shift变换，改变时间分布
    # shift>1: 更多步数集中在接近数据的区域(小噪声)
    sigma = (shift * sigma / (1 + (shift - 1) * sigma))
    
    return sigma

# 示例: shift=5.0, steps=20
# 原始: [1.00, 0.95, 0.90, ..., 0.05]
# Shift后: [1.00, 0.83, 0.69, ..., 0.01] 
# 效果: 后期步数更密集，精细调整
```

#### 2.4 DPM++ Solver的Step函数

**核心更新算法**:
```python
# 文件: wan/utils/fm_solvers.py, 行: 708-805

def step(self, model_output, timestep, sample, generator=None, ...):
    """
    DPM++ Solver的单步更新
    
    Args:
        model_output: DiT预测的速度 v_θ(x_t, t) [16, 21, 64, 64]
        timestep: 当前时间步 t
        sample: 当前latent x_t [16, 21, 64, 64]
    
    Returns:
        prev_sample: 更新后的latent x_{t-Δt} [16, 21, 64, 64]
    """
    
    # 1. 转换模型输出 (如果需要)
    model_output = self.convert_model_output(model_output, sample=sample)
    
    # 2. 更新历史输出 (多步方法)
    for i in range(self.config.solver_order - 1):
        self.model_outputs[i] = self.model_outputs[i + 1]
    self.model_outputs[-1] = model_output
    
    # 3. 上溯到float32避免精度问题
    sample = sample.to(torch.float32)
    
    # 4. 根据求解器阶数选择更新方法
    if self.config.solver_order == 1:
        # 一阶Euler方法
        prev_sample = self.dpm_solver_first_order_update(
            model_output, sample=sample, noise=None
        )
    elif self.config.solver_order == 2:
        # 二阶方法 (默认)
        prev_sample = self.multistep_dpm_solver_second_order_update(
            self.model_outputs, sample=sample, noise=None
        )
    else:
        # 三阶方法
        prev_sample = self.multistep_dpm_solver_third_order_update(
            self.model_outputs, sample=sample
        )
    
    # 5. 转换回原始dtype
    prev_sample = prev_sample.to(model_output.dtype)
    
    # 6. 更新步骤索引
    self._step_index += 1
    
    return prev_sample

# ========== 一阶更新 (Euler方法) ==========
def dpm_solver_first_order_update(self, model_output, sample, noise=None):
    """
    最简单的Euler方法: x_{t-Δt} = x_t - Δt * v_θ(x_t, t)
    
    在Flow Matching中:
    - v_θ预测的是从噪声到数据的"速度"
    - 更新就是沿着速度方向前进一步
    """
    timestep = self.timesteps[self.step_index]
    prev_timestep = (
        self.timesteps[self.step_index + 1] 
        if self.step_index + 1 < len(self.timesteps) 
        else torch.tensor(0.0)
    )
    
    # 计算时间步长
    lambda_t = self.lambda_t[self.step_index]
    lambda_s = self.lambda_t[self.step_index + 1] if self.step_index + 1 < len(self.timesteps) else self.terminal_lambda_t
    
    # 计算系数
    h = lambda_s - lambda_t
    
    # Euler更新
    # 在Flow Matching中: x_{t-Δt} = x_t + h * v_θ(x_t, t)
    prev_sample = (
        self.sigma_t[self.step_index + 1] / self.sigma_t[self.step_index]
    ) * sample - (torch.exp(h) - 1.0) * model_output
    
    return prev_sample

# ========== 二阶更新 (默认) ==========
def multistep_dpm_solver_second_order_update(self, model_output_list, sample, noise=None):
    """
    二阶DPM Solver - 更准确的更新
    使用当前和上一步的model_output进行更精确的积分
    """
    timestep_list = [
        self.timesteps[self.step_index - 1],
        self.timesteps[self.step_index],
    ]
    model_output_0, model_output_1 = model_output_list[-2], model_output_list[-1]
    
    # 计算lambda和系数
    lambda_t, lambda_s = self.lambda_t[self.step_index - 1], self.lambda_t[self.step_index]
    lambda_s1 = self.lambda_t[self.step_index + 1] if self.step_index + 1 < len(self.timesteps) else self.terminal_lambda_t
    
    h, h_0 = lambda_s1 - lambda_t, lambda_s - lambda_t
    r0 = h_0 / h
    
    # 二阶更新公式 (使用线性组合两步的model_output)
    D0, D1 = model_output_0, model_output_1
    
    prev_sample = (
        (self.sigma_t[self.step_index + 1] / self.sigma_t[self.step_index]) * sample
        - (torch.exp(h) - 1.0) * D1
        - 0.5 * (torch.exp(h) - 1.0 - h) / h * (D1 - D0) / r0
    )
    
    return prev_sample
```

**关键理解**:
1. **Flow Matching vs DDPM**:
   - DDPM: 预测噪声ε，通过 $x_{t-1} = \frac{1}{\sqrt{\alpha_t}}(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}}\epsilon_\theta)$
   - Flow Matching: 预测速度v，通过 $x_{t-Δt} = x_t + \int_t^{t-Δt} v_\theta(x_s, s)ds$

2. **多步求解器**:
   - 一阶: 简单Euler步进
   - 二阶: 使用当前和上一步的速度，更准确
   - 三阶: 使用更多历史信息，最准确但需要更多内存

3. **Shift的作用**:
   - 控制时间步的分布
   - shift>1: 更多步数用于精细调整(接近数据端)
   - shift<1: 更多步数用于粗略去噪(接近噪声端)

# 文件: wan/modules/animate/model_animate.py

def forward(self, x, t, clip_fea, context, seq_len, 
            y=None, pose_latents=None, face_pixel_values=None):
    
    # ========== 输入合并 ==========
    # x: [16, 21, 64, 64] 目标帧噪声
    # y: [20, 21, 64, 64] 参考条件
    
    if y is not None:
        x = [torch.cat([u, v], dim=0) for u, v in zip(x, y)]
        # x: [36, 21, 64, 64]
        # 解释:
        #   通道0-15: 目标帧噪声 (需要去噪的内容)
        #   通道16-19: mask (标记参考区域)
        #   通道20-35: 参考latent (参考帧的内容)
    
    # ========== Patch Embedding ==========
    # Conv3D: 将3D latent切分成patches
    x = [self.patch_embedding(u.unsqueeze(0)) for u in x]
    # [36, 21, 64, 64] -> [1, 5120, 21, 32, 32]
    # 解释:
    #   空间下采样: 64x64 -> 32x32 (patch size=2)
    #   通道扩展: 36 -> 5120 (embedding维度)
    
    # ========== 姿态条件注入 (加法) ==========
    pose_latents = [self.pose_patch_embedding(u) for u in pose_latents]
    # [16, 20, 64, 64] -> [1, 5120, 20, 32, 32]
    
    for x_, pose_ in zip(x, pose_latents):
        x_[:, :, 1:] += pose_  # 除第0帧外都加上pose
        # 解释: 第0帧是参考图像,不需要pose约束
        #       第1-20帧是待生成帧,需要pose引导
    
    # ========== 面部条件准备 ==========
    motion_vec = self.motion_encoder.get_motion(face_pixel_values)
    # [B*77, 3, 512, 512] -> [77, 512]
    
    motion_vec = self.face_encoder(motion_vec)
    # [77, 512] -> [21, 5, 5120]
    
    # ========== Flatten ==========
    x = [u.flatten(2).transpose(1, 2) for u in x]
    # [1, 5120, 21, 32, 32] -> [1, 21*32*32, 5120]
    #                         = [1, 21504, 5120]
    # 解释: 将3D patches flatten成1D序列
    #   21504个token,每个5120维
    
    # ========== 时间步条件 (Modulation) ==========
    t_emb = sinusoidal_embedding_1d(freq_dim, t)  # [B, 256]
    e = self.time_embedding(t_emb)                # [B, 5120]
    e0 = self.time_projection(e).unflatten(1, (6, dim))  # [B, 6, 5120]
    # 解释: 6组参数用于modulation
    #   shift1, scale1, gate1 (Self-Attn)
    #   shift2, scale2, gate2 (FFN)
    
    # ========== 文本+CLIP条件 (拼接) ==========
    context = self.text_embedding(context)        # [B, 512, 5120]
    context_clip = self.img_emb(clip_fea)        # [B, 257, 5120]
    context = torch.concat([context_clip, context], dim=1)  # [B, 769, 5120]
    # 解释: CLIP在前,文本在后,作为cross-attention的K,V
    
    # ========== Transformer Blocks ==========
    for idx, block in enumerate(self.blocks):  # 40层
        # Self-Attention + Cross-Attention + FFN
        x = block(
            x=x,                    # [B, 21504, 5120]
            e=e0,                   # [B, 6, 5120] 时间步modulation
            seq_lens=seq_lens,      # [B]
            grid_sizes=grid_sizes,  # [B, 3]
            freqs=self.freqs,       # [1024, 128] RoPE
            context=context,        # [B, 769, 5120] 文本+CLIP
            context_lens=None
        )
        
        # 每5层注入面部条件
        if idx % 5 == 0:
            face_residual = self.face_adapter(
                x=x,                # [B, 21504, 5120] DiT特征(Q)
                motion_vec=motion_vec  # [B, 21, 5, 5120] 面部特征(K,V)
            )
            x = x + face_residual  # 残差连接
    
    # ========== Output Head ==========
    x = self.head(x, e)  # [B, 21504, 5120] -> [B, 21504, 16]
    # 解释: 输出16通道的速度场
    
    # ========== Unpatchify ==========
    x = self.unpatchify(x, grid_sizes)
    # [B, 21504, 16] -> [16, 21, 64, 64]
    # 解释: 重建3D latent shape
    
    return [u.float() for u in x]  # 预测的速度 v_θ(x_t, t)

#### 3.3 Transformer Block内的条件交互

```python
# 单个Transformer Block的处理
def transformer_block_forward(x, e, context, motion_vec):
    # x: [B, 21504, 5120] - 包含目标帧+参考帧的token序列
    # e: [B, 6, 5120]     - 时间步调制
    # context: [B, 769, 5120] - 文本+CLIP
    # motion_vec: [B, 21, 5, 5120] - 面部特征
    
    # ========== Self-Attention ==========
    # 作用: 目标帧token之间、目标帧与参考帧之间的交互
    
    # 1. Modulation
    shift1, scale1, gate1 = e[:, 0], e[:, 1], e[:, 2]
    x_in = norm(x) * (1 + scale1) + shift1
    
    # 2. Self-Attention
    # Query, Key, Value都来自x
    q = q_proj(x_in)  # [B, 21504, num_heads, head_dim]
    k = k_proj(x_in)  # [B, 21504, num_heads, head_dim]
    v = v_proj(x_in)  # [B, 21504, num_heads, head_dim]
    
    # 应用RoPE (3D位置编码)
    q = rope_apply(q, grid_sizes, freqs)  # 编码3D位置(T, H, W)
    k = rope_apply(k, grid_sizes, freqs)
    
    # Attention计算
    attn_out = flash_attention(q, k, v)  # [B, 21504, 5120]
    # 关键: 每个token可以attend到所有其他token
    #   目标帧token -> 参考帧token: 获取参考信息
    #   目标帧token -> 目标帧token: 内部一致性
    #   参考帧token也参与,但通过mask保持不变
    
    # 3. Gated residual
    x = x + gate1 * attn_out
    
    # ========== Cross-Attention ==========
    # 作用: 从文本+CLIP条件中获取语义信息
    
    # 1. Query from video tokens
    q = q_proj(norm(x))  # [B, 21504, num_heads, head_dim]
    
    # 2. Key, Value from text+CLIP
    # 文本路径
    k_text = k_proj(context[:, 257:])  # [B, 512, num_heads, head_dim]
    v_text = v_proj(context[:, 257:])  # [B, 512, num_heads, head_dim]
    attn_text = flash_attention(q, k_text, v_text)
    
    # CLIP路径
    k_clip = k_proj(context[:, :257])  # [B, 257, num_heads, head_dim]
    v_clip = v_proj(context[:, :257])  # [B, 257, num_heads, head_dim]
    attn_clip = flash_attention(q, k_clip, v_clip)
    
    # 融合两路
    attn_out = attn_text + attn_clip  # [B, 21504, 5120]
    
    x = x + attn_out
    
    # ========== FFN ==========
    shift2, scale2, gate2 = e[:, 3], e[:, 4], e[:, 5]
    x_in = norm(x) * (1 + scale2) + shift2
    ffn_out = ffn(x_in)  # [B, 21504, 5120]
    x = x + gate2 * ffn_out
    
    return x

# ========== Face Adapter (每5层) ==========
def face_adapter_forward(x, motion_vec):
    # x: [B, 21504, 5120] - DiT特征
    # motion_vec: [B, 21, 5, 5120] - 面部特征
    
    # 1. Query from DiT
    q = q_proj(x)  # [B, 21504, 40, 128]
    
    # 按时间分组 (21帧)
    q = rearrange(q, "B (T S) H D -> (B T) S H D", T=21)
    # [(B*21), seq_per_frame, 40, 128]
    
    # 2. Key, Value from Face
    kv = kv_proj(motion_vec)  # [B, 21, 5, 40*128*2]
    k, v = split(kv, 2)  # 各 [B, 21, 5, 40, 128]
    
    k = rearrange(k, "B T N H D -> (B T) N H D")  # [(B*21), 5, 40, 128]
    v = rearrange(v, "B T N H D -> (B T) N H D")
    
    # 3. Attention: 每帧的空间token查询对应帧的5个面部特征
    attn = attention(q, k, v)  # [(B*21), seq_per_frame, 5120]
    
    # 4. 重组
    attn = rearrange(attn, "(B T) S C -> B (T S) C", T=21)  # [B, 21504, 5120]
    
    # 5. 输出投影
    out = out_proj(attn)  # [B, 21504, 5120]
    
    return out  # 作为残差加到x上
```

**关键机制总结**:

1. **参考帧如何影响目标帧**:
   - 通过Self-Attention: 目标帧token直接attend到参考帧token
   - 参考帧的mask=1保证其特征稳定,作为"锚点"
   - 目标帧在去噪时会"模仿"参考帧的风格和内容

2. **多条件的协同**:
   - **结构级** (Pose): 加法注入,最强约束
   - **语义级** (Text+CLIP): Cross-attention,每层都有
   - **细节级** (Face): 残差注入,每5层一次
   - **时序级** (Reference y): Self-attention交互
   - **时间级** (Timestep t): Modulation调制

3. **去噪的渐进性**:
   - t=1000 (σ=1.0): 纯噪声,条件引导微弱
   - t=500 (σ≈0.5): 大致结构出现,条件开始生效
   - t=100 (σ≈0.1): 细节完善,条件引导强
   - t=10 (σ≈0.01): 最终精修,强烈受条件约束

## 总结

### 核心设计理念
1. **多模态融合**: 文本、视觉、姿态、表情多条件协同
2. **分层注入**: 不同条件在不同层级注入，避免信息冲突
3. **残差机制**: 面部条件通过残差连接，保持主干特征稳定
4. **时序连贯**: 通过temporal reference实现跨clip一致性
5. **区域控制**: Replacement模式通过mask实现精细空间控制

### 条件优先级
1. **结构级** (最强): 姿态条件 (直接加到embedding)
2. **语义级**: 文本+CLIP (每层cross-attention)
3. **细节级**: 面部条件 (每5层注入)
4. **时序级**: 参考帧y (输入阶段融合)
5. **环境级**: 背景+mask (Replacement模式)

### 优化建议
- **快速生成**: 关闭CFG (guide_scale=1.0)
- **精细控制**: 使用CFG + 5帧temporal reference
- **环境保留**: 使用Replacement模式 + 精细mask
- **内存优化**: 减小clip_len (如49帧)，增加overlap

## Mask机制详解：0/1取值对条件的影响

### 一、Mask的基本概念

在Wan2.2 Animate中，**mask是一个4通道的二值掩码**，用于区分目标区域（前景）和背景区域：

```python
# mask的维度: [1, 4, lat_t, lat_h, lat_w]
# - 4个通道对应VAE的4个latent通道
# - lat_t: 时间维度的latent帧数
# - lat_h, lat_w: 空间维度的latent尺寸

# mask取值含义：
# mask = 1: 参考帧区域（需要保留的部分，通常是前mask_len帧）
# mask = 0: 目标生成区域（需要生成新内容的部分）
```

### 二、Mask的生成机制

#### 2.1 Animation模式的Mask生成

```python
# 代码位置：wan/animate.py, line 227-237
def get_i2v_mask(self, lat_t, lat_h, lat_w, mask_len=1, mask_pixel_values=None, device="cuda"):
    """
    生成image-to-video的mask
    
    参数：
        lat_t: latent时间长度（压缩后的帧数）
        lat_h, lat_w: latent空间尺寸
        mask_len: 参考帧数量（默认为1，即首帧）
        mask_pixel_values: 自定义mask（Replacement模式使用）
    """
    # 步骤1：创建全零mask（表示全部需要生成）
    if mask_pixel_values is None:
        # 原始视频帧数 = (lat_t - 1) * 4 + 1
        msk = torch.zeros(1, (lat_t-1) * 4 + 1, lat_h, lat_w, device=device)
    else:
        msk = mask_pixel_values.clone()
    
    # 步骤2：将前mask_len帧设为1（表示参考帧，不生成）
    msk[:, :mask_len] = 1
    
    # 步骤3：将首帧复制4次（对应VAE的时间下采样stride=4）
    # 因为VAE编码时首帧不下采样，所以需要repeat 4次保持对齐
    msk = torch.concat([
        torch.repeat_interleave(msk[:, 0:1], repeats=4, dim=1),  # 首帧重复4次
        msk[:, 1:]  # 后续帧保持不变
    ], dim=1)
    
    # 步骤4：重组为latent空间的形状 [1, t, 4, h, w] -> [4, t, h, w]
    msk = msk.view(1, msk.shape[1] // 4, 4, lat_h, lat_w)  # [1, t, 4, h, w]
    msk = msk.transpose(1, 2)[0]  # [4, t, h, w]
    
    return msk

# 使用示例（Animation模式）：
mask_ref_len = 1  # 只使用首帧作为参考
msk_ref = self.get_i2v_mask(lat_t, lat_h, lat_w, mask_ref_len, device=self.device)
# msk_ref形状: [4, lat_t, lat_h, lat_w]
# msk_ref[:, 0:1, :, :] = 1.0  （首帧全为1）
# msk_ref[:, 1:, :, :] = 0.0    （其他帧全为0）
```

**Animation模式的Mask结构**：
```
时间维度可视化（假设lat_t=21）:
Frame:  0    1    2    3    ...   20
Mask:  [1]  [0]  [0]  [0]  ...  [0]
        ↑
    参考帧（保留）   目标帧（生成新内容）
```

#### 3.2 在DiT模型中的处理

```python
# 代码位置：wan/modules/animate/model_animate.py, line 384-386
def forward(self, x, t, clip_fea, context, seq_len, y=None, pose_latents=None, face_pixel_values=None):
    # x: 目标latent（带噪声） [bs, 4, lat_t, lat_h, lat_w]
    # y: 参考latent（包含mask） [bs, 8, 2*lat_t, lat_h, lat_w]
    
    # 步骤1：将目标与参考拼接在通道维度
    if y is not None:

        # 通道0-3: 目标latent（待生成）
        # 通道4-7: 参考/背景mask
        # 通道8-11: 参考/背景latent
    
    # 步骤2：Patch Embedding
    x = [self.patch_embedding(u.unsqueeze(0)) for u in x]
    # 将12通道投影到5120维
    # patch_embedding: Conv3d(12, 5120, kernel_size=2, stride=2)
```

**关键点**：Mask和Latent通过通道拼接进入模型，让DiT能够同时"看到"：
- **哪里需要生成**（mask=0的区域）
- **哪里需要保留**（mask=1的区域）
- **保留区域的内容是什么**（对应的latent值）

### 四、Mask的作用原理

#### 4.1 Mask=1（保留区域）的影响

当mask=1时，表示该区域是**参考内容，应当保留**：

```python
# 在Self-Attention中的作用：
# 目标token会查询参考token，从mask=1的区域提取特征

# 假设空间位置(i,j)的mask=1（背景区域）：
# 对应的参考latent: y[:, 8:12, :, i, j]  （后4通道是真实内容）
# 对应的mask值:     y[:, 4:8, :, i, j] = 1.0

# Self-Attention计算：
Q = x_target  # 目标区域的query [B*H, S_target, D]
K = x_ref     # 参考区域的key   [B*H, S_ref, D]
V = x_ref     # 参考区域的value [B*H, S_ref, D]

attention_weights = softmax(Q @ K.T / sqrt(D))  # [B*H, S_target, S_ref]
output = attention_weights @ V  # [B*H, S_target, D]

# 对于mask=1的参考位置，其对应的K和V包含真实的背景内容
# 目标区域的生成会受到这些背景特征的引导
# 结果：模型倾向于在对应位置保持背景的稳定性
```

**物理意义**：
1. **提供空间对齐信息**：告诉模型"这个位置已经有内容了"
2. **约束生成范围**：模型知道不应该在mask=1的区域生成新内容
3. **特征引导**：mask=1区域的真实latent作为强参考，通过attention传播到目标区域

#### 4.2 Mask=0（生成区域）的影响

当mask=0时，表示该区域是**目标区域，需要生成新内容**：

```python
# 在Self-Attention中的作用：
# 目标token可以自由关注其他目标token和参考token

# 假设空间位置(i,j)的mask=0（人物区域）：
# 对应的参考latent: y[:, 8:12, :, i, j] = 0或背景内容
# 对应的mask值:     y[:, 4:8, :, i, j] = 0.0

# Self-Attention中，mask=0的位置：
# 1. 对应的K和V权重较低（因为latent内容无效）
# 2. 目标区域主要依赖其他条件：
#    - Pose latents（结构引导）
#    - Face features（表情引导）
#    - Text/CLIP context（语义引导）
#    - 其他时间帧的目标内容（时序一致性）

# 生成自由度：
# mask=0区域允许模型根据多模态条件自由生成
# 不受参考帧空间位置的强约束
```

**物理意义**：
1. **标记生成区域**：明确告诉模型"这个位置需要新内容"
2. **降低参考权重**：mask=0对应的参考latent不起主导作用
3. **激活条件生成**：模型更依赖Pose、Face、Text等条件

#### 4.3 Mask的边界效应

Mask在前景-背景边界处起到关键作用：

```python
# 边界区域示例（简化为1D）：
mask:   [1, 1, 1, 0.5, 0, 0, 0, 0.5, 1, 1]
        └────┬────┘ │ └───┬───┘ │ └──┬──┘
          背景   过渡  前景  过渡  背景

# 在实际实现中，mask是二值的（0或1），但通过插值和attention可能产生软边界

# 边界效应的作用：
# 1. 平滑过渡：避免前景和背景的突变
# 2. 融合约束：确保生成的人物与背景自然衔接
# 3. 遮挡处理：处理人物边缘与背景的遮挡关系
```

### 五、环境因素的实现原理

#### 5.1 背景保留机制

#### 5.2 Self-Attention中的背景引导

```python
# 在Transformer Block中的处理：

def forward(self, x, e, seq_lens, grid_sizes, freqs, context, context_lens):
    # x: [B, S, D] 包含目标latent和参考latent的token序列
    
    # 步骤1：时空Self-Attention
    # 分离目标和参考：
    B = x.shape[0] // 2  # 因为使用了CFG，batch翻倍
    x_target = x[:B]  # 目标帧tokens
    x_ref = x[B:]     # 参考帧tokens（包含mask信息）
    
    # 步骤2：计算attention
    # Q从目标帧，K/V从目标+参考
    Q = self.norm_q(x_target)
    K = self.norm_k(torch.cat([x_target, x_ref]))
    V = self.norm_v(torch.cat([x_target, x_ref]))
    
    attention_output = scaled_dot_product_attention(Q, K, V)
    # 关键：目标帧的每个token会关注：
    # 1. 其他目标帧tokens（时序一致性）
    # 2. 参考帧tokens（背景引导）
    #    - mask=1的token有强特征（真实背景）
    #    - mask=0的token特征弱（无效内容）
    
    # 结果：
    # 对于空间位置(i,j):
    # - 如果ref_mask[i,j]=1: 目标帧在(i,j)受到强背景约束
    # - 如果ref_mask[i,j]=0: 目标帧在(i,j)自由生成
```

**背景引导的数学表达**：

设目标帧token为 $q_t$，参考帧tokens为 $\{k_r, v_r\}$，对应mask为 $m_r$：

$$
\text{Attention}(q_t) = \sum_{r} \underbrace{\text{softmax}\left(\frac{q_t \cdot k_r}{\sqrt{d}}\right)}_{\text{attention weight}} \cdot \underbrace{v_r}_{\text{value}}
$$

当 $m_r = 1$（背景区域）时：
- $v_r$ 包含真实背景的强特征
- attention weight自然偏高（因为特征清晰）
- $q_t$ 被拉向背景的表示

当 $m_r = 0$（前景区域）时：
- $v_r$ 是无效或弱特征
- attention weight自然偏低
- $q_t$ 主要依赖其他条件（Pose、Face等）

#### 5.3 环境光照和空间关系的保留

```python

# 3. 颜色协调：

# 生成的人物色彩与环境协调

# 具体实现在Transformer的多层传播中：
for idx, block in enumerate(self.blocks):

    # 每层attention都会考虑背景特征

```

## Relighting LoRA机制详解

### 一、Relighting LoRA概述

**Relighting LoRA**是Wan2.2 Animate专门为**角色替换（Replacement）模式**设计的轻量级适配器，用于解决角色替换时的**光照一致性**问题。

#### 1.1 核心问题

在Replacement模式下，当替换场景中的角色时，会遇到以下挑战：

```python
# 问题场景：
# 原始场景：室内黄昏光线，窗户斜射柔和暖光
# 参考图像：可能是明亮正面光
# 生成结果：如果不调整，新角色光照与背景不符

原始场景光照：
┌──────────────────┐
│  🌅 <- 斜射光   │
│  🪟             │  背景：暖黄色调
│    🧍 原角色   │  光源：窗户（左上）
└──────────────────┘

直接替换（无Relighting）：
┌──────────────────┐
│  🌅 <- 斜射光   │
│  🪟             │  背景：暖黄色调（保留）
│    🧍 新角色   │  ❌ 新角色：正面白光（不协调）
└──────────────────┘

使用Relighting LoRA：
┌──────────────────┐
│  🌅 <- 斜射光   │
│  🪟             │  背景：暖黄色调（保留）
│    🧍 新角色   │  ✅ 新角色：匹配背景光照
└──────────────────┘
```

#### 1.2 设计目标

1. **光照适配**：使生成的角色适应背景的光照条件
2. **轻量高效**：仅微调关键模块，不改变模型主体
3. **即插即用**：可选启用，不影响Animation模式

### 二、LoRA技术原理

#### 2.1 LoRA（Low-Rank Adaptation）基础

LoRA通过**低秩分解**在预训练模型上添加可训练的旁路：

```python
# 原始Linear层：
y = W_0 @ x  # W_0: [d_out, d_in]，参数量 = d_out × d_in

# 添加LoRA后：
y = W_0 @ x + (B @ A) @ x  # A: [r, d_in], B: [d_out, r]
                            # 新增参数量 = r × (d_in + d_out)
                            # 当 r << min(d_in, d_out) 时，参数量大幅减少

# 其中：
# - W_0: 冻结的原始权重（不更新）
# - A, B: 可训练的低秩矩阵（需要更新）
# - r: 秩（rank），控制适配能力和参数量的平衡
```

**数学表达**：

原始前向传播：
$$
y = W_0 x
$$

LoRA前向传播：
$$
y = W_0 x + \Delta W x = W_0 x + BA x
$$

其中：
- $W_0 \in \mathbb{R}^{d_{out} \times d_{in}}$：原始权重（冻结）
- $A \in \mathbb{R}^{r \times d_{in}}$，$B \in \mathbb{R}^{d_{out} \times r}$：LoRA权重
- $r$：秩（Wan2.2中设为128）

**参数量对比**：
```python
# 假设 d_in = d_out = 5120 (Wan2.2的hidden_dim)
原始参数量 = 5120 × 5120 = 26,214,400

# LoRA参数量 (r=128)
LoRA参数量 = 128 × 5120 × 2 = 1,310,720
压缩比 = 26,214,400 / 1,310,720 ≈ 20倍

# 仅占原始参数的5%！
```

#### 2.2 LoRA的优势

1. **参数高效**：仅需训练5%的参数
2. **训练快速**：减少计算量和显存占用
3. **模块化**：可以为不同任务训练不同的LoRA
4. **可叠加**：多个LoRA可以组合使用

### 三、Relighting LoRA的实现

#### 3.1 目标模块选择

```python
# 代码位置：wan/modules/animate/animate_utils.py, line 7-19
def get_loraconfig(transformer, rank=128, alpha=128, init_lora_weights="gaussian"):
    """
    配置LoRA应用的目标模块
    
    参数：
        transformer: DiT模型
        rank: LoRA的秩（控制容量）
        alpha: LoRA的缩放系数（控制影响强度）
        init_lora_weights: 初始化方式
    """
    target_modules = []
    for name, module in transformer.named_modules():
        # 选择条件：
        # 1. 在transformer blocks中
        # 2. 不是face相关模块（face已有专门的适配器）
        # 3. 不是modulation层（时间条件层，保持稳定）
        # 4. 是Linear层（全连接层）
        if "blocks" in name and "face" not in name and "modulation" not in name and isinstance(module, torch.nn.Linear):
            target_modules.append(name)
    
    # 创建LoRA配置
    transformer_lora_config = LoraConfig(
        r=rank,              # 秩=128
        lora_alpha=alpha,    # 缩放=128（alpha/r=1.0，即等比例影响）
        init_lora_weights=init_lora_weights,  # 高斯初始化
        target_modules=target_modules,
    )
    return transformer_lora_config
```

**加载前后对比**：

```python
# 加载前（普通DiT）：
class Linear(nn.Module):
    def forward(self, x):
        return self.weight @ x  # [d_out, d_in] @ [B, L, d_in]

# 加载后（DiT + LoRA）：
class LinearWithLoRA(nn.Module):
    def forward(self, x):
        base_output = self.base_layer.weight @ x  # 原始输出
        lora_output = self.lora_B @ (self.lora_A @ x)  # LoRA输出
        return base_output + lora_output  # 组合输出
```

#### 3.3 LoRA在DiT中的作用位置

```python
# 在DiT的每个Transformer Block中：

def forward(self, x, e, seq_lens, grid_sizes, freqs, context, context_lens):
    # 1. Self-Attention（应用LoRA）
    q = self.self_attn.q(norm(x))  # LoRA修正Q投影
    k = self.self_attn.k(norm(x))  # LoRA修正K投影
    v = self.self_attn.v(norm(x))  # LoRA修正V投影
    attn_out = attention(q, k, v)
    x = x + self.self_attn.o(attn_out)  # LoRA修正输出投影
    
    # 2. Cross-Attention（应用LoRA）
    q = self.cross_attn.q(x)  # LoRA修正Q投影
    k = self.cross_attn.k(context)  # LoRA修正K投影
    v = self.cross_attn.v(context)  # LoRA修正V投影
    cross_out = attention(q, k, v)
    x = x + self.cross_attn.o(cross_out)  # LoRA修正输出投影
    
    # 3. FFN（应用LoRA）
    ffn_out = self.ffn[1](gelu(self.ffn[0](norm(x))))
    #              LoRA↑          LoRA↑
    x = x + ffn_out
    
    return x
```

### 五、Relighting LoRA的工作原理

#### 5.1 特征空间的光照调整

```python

Δf可能包含：

- 方向光信息（光照来源方向）
- 阴影强度（对比度）
```

**可视化示例**：

```
Self-Attention中的LoRA作用：

原始Query（无LoRA）：
Q = W_q @ x  # 查询"这个位置应该是什么样"

LoRA调整后的Query：
Q' = W_q @ x + B_q @ A_q @ x
   = Q + ΔQ

ΔQ的含义：
"考虑背景光照后，这个位置应该如何调整"
例如：
- 如果背景是暖光，ΔQ会偏向暖色调特征
- 如果背景是侧光，ΔQ会增强阴影侧的权重
```

#### 5.2 多层级的光照传播

```python
# LoRA在40层Transformer中逐层调整：

Layer 1-10（低层）：
- 调整局部纹理和细节
- 修正边缘光照过渡
- 适配小范围阴影

Layer 11-25（中层）：
- 调整区域色调
- 协调人物与背景的色彩关系
- 调整中等尺度光影

Layer 26-40（高层）：
- 调整全局光照风格
- 统一整体色温
- 确保光照方向一致性
```

#### 5.3 与Mask机制的协同

```python
# LoRA和Mask机制协同工作：

在DiT的forward中：
x_input = [
    latents,      # [4, t, h, w] 目标latent
    msk_reft,     # [4, t, h, w] mask（背景=1）
    y_reft        # [4, t, h, w] 背景latent
]

# Mask告诉模型"哪里是背景（需要参考光照）"
# LoRA学习"如何提取和应用背景的光照信息"

for layer in transformer_blocks:
    # Self-Attention：
    # 目标区域(mask=0)关注背景区域(mask=1)
    attn_output = self_attention(x_input)
    
    # LoRA在这里调整attention的权重：
    # 1. 增强对背景光照特征的关注
    # 2. 将背景光照特征传播到前景
    attn_output = attn_output + lora_adjustment(x_input)
    
    x_input = x_input + attn_output
```

#### 8.3 数学原理总结

核心公式：
$$
\mathbf{y} = \mathbf{W}_0 \mathbf{x} + \frac{\alpha}{r} \mathbf{B} \mathbf{A} \mathbf{x}
$$

其中：
- $\mathbf{W}_0$：预训练权重（frozen）
- $\mathbf{A}, \mathbf{B}$：LoRA权重（trainable）
- $\alpha/r = 1.0$：缩放系数

$$
\Delta \mathbf{f}_{\text{lighting}} = \mathbf{B} \mathbf{A} \mathbf{x}_{\text{background}}
$$

通过低秩分解学习从背景特征到光照调整的映射。

## Mask机制原理深度剖析

### 一、Mask效果来源：训练习得 vs 公式计算

用户的核心疑问是：**"Mask实现这个效果是通过训练得来的吗？还是通过我主动设置mask为0/1后，通过公式计算得到的呢？"**

**答案是：两者结合。**

1.  **公式计算（输入端）**：
    -   **你（用户/代码）主动设置**了Mask的值（0或1）以及对应的参考内容。
    -   通过`get_i2v_mask`等函数，按照特定的公式构造了输入张量。
    -   这是一个**确定性**的数据准备过程。

2.  **训练习得（模型端）**：
    -   模型**通过训练**学会了"看到Mask=1时保留内容，看到Mask=0时生成内容"的行为。
    -   模型内部**没有**写死类似 `if mask==1: output = input` 的硬逻辑。
    -   相反，Mask是作为一个**特征通道**输入给Transformer的。Transformer通过海量数据训练，学习到了Mask通道的语义含义。

**形象比喻**：
-   **Mask** 就像是给画师（模型）的**标注**。
-   你在画布上某些区域涂上红色标记（Mask=1），并贴上照片（参考帧），告诉画师"这里照着画"。
-   在其他区域涂上绿色标记（Mask=0），告诉画师"这里自由发挥"。
-   **公式计算**就是你涂标记的过程。
-   **训练习得**就是画师能够看懂这些标记并执行指令的能力。

### 二、结合代码分析：如何通过Mask设定参考帧

在Wan2.2中，通过Mask将某一帧设为"参考帧"，本质上是构造了一个包含**【噪声+Mask+参考图】**的复合输入。

#### 2.1 构造"复合输入"

代码位置：`wan/modules/animate/model_animate.py` 的 `forward` 函数：

```python
# x: 待生成的latent（全是噪声），形状 [B, 4, T, H, W]
# y: 参考信息（Mask + 参考图），形状 [B, 8, T, H, W]

if y is not None:
    # 核心步骤：通道拼接！
    x = [torch.cat([u, v], dim=0) for u, v in zip(x, y)]
    # 结果 x 的通道数变为 12 (4+8)
    # Channel 0-3: 噪声 (Target)
    # Channel 4-7: Mask
    # Channel 8-11: 参考图 (Reference Content)
```

这意味着，对于Transformer的每一个Token（对应视频的一个时空块），它都包含了三部分信息。

#### 2.2 设定参考帧的逻辑（Animation模式）

代码位置：`wan/animate.py` 的 `get_i2v_mask` 函数。

假设我们要将**第0帧**设为参考帧，**第1-N帧**设为生成帧：

```python
# 1. 构造Mask张量
# mask_len = 1 (表示前1帧是参考)
msk = torch.zeros(...)  # 初始化全0
msk[:, :mask_len] = 1   # 将时间维度前mask_len帧设为1

# 2. 构造参考图像张量 (y_ref)
# ref_latents: 真实的图片latent
# 在 t=0 时: Mask=1, Content=真实图片
# 在 t>0 时: Mask=0, Content=重复填充或无效值（模型会忽略它）

# 3. 拼接
y = cat(mask, ref_latents)
```

**Transformer视角的输入数据**：

| 时间步 | Mask通道值 | 参考内容通道值 | 噪声通道值 | 模型学到的行为 |
| :--- | :--- | :--- | :--- | :--- |
| **t=0 (参考帧)** | **1.0** (高亮) | **真实图片特征** | 随机噪声 | **"Mask是1，我应该忽略噪声，直接把参考内容搬运过去"** |
| **t>0 (生成帧)** | **0.0** (关闭) | 无效/零 | 随机噪声 | **"Mask是0，参考内容无效，我要根据上下文和噪声去噪生成新图"** |

#### 2.3 设定替换区域的逻辑（Replacement模式）

在Replacement模式下，Mask不再是时间维度的切分，而是**空间维度**的切分。

```python
# 代码示意
if replace_flag:
    # 1. 读取用户上传的Mask图片（前景=0，背景=1）
    mask_pixel_values = ... 
    
    # 2. 构造Mask
    msk_reft = get_i2v_mask(..., mask_pixel_values=mask_pixel_values)
    # 此时msk_reft在每一帧的空间上都是有0有1的
    
    # 3. 构造背景参考
    y_reft = cat(msk_reft, bg_latents)
```

**Transformer视角的空间Token**：

| 空间位置 | Mask通道值 | 参考内容通道值 | 模型学到的行为 |
| :--- | :--- | :--- | :--- |
| **背景区域 (pixel=[0,0])** | **1.0** | **真实背景** | **"保留原始背景"** |
| **人物区域 (pixel=[100,100])** | **0.0** | 无效 | **"这里要生成新的人"** |
| **边界区域 (pixel=[50,50])** | **0.5** (插值后) | 混合特征 | **"这里要平滑过渡"** |

### 三、原理总结

你并没有通过公式直接计算出"最终结果"，而是通过公式计算出了**"对模型的指令（Mask）"**。

1.  **输入端**：通过 `cat([noise, mask, reference])` 将指令和参考素材"埋"进了输入数据中。
2.  **模型端**：Transformer 的 `Patch Embedding` 层将这12个通道的数据映射为隐向量。
3.  **Attention机制**：
    -   当Mask=1时，Token内部包含强烈的"我是参考帧"信号。Self-Attention机制会倾向于保持这个Token的稳定性，并让其他Token（Mask=0的那些）来关注它（Copy机制）。
    -   当Mask=0时，Token信号较弱，模型转而依赖Text Condition、Face Adapter等条件来构建内容。

所以，是**训练**赋予了Mask以此功能的**物理意义**，而**公式代码**则是你在**推理**阶段行使这一控制权的手段。
