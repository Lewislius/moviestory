## 1. 项目整体架构概览

本项目将两个独立系统结合：

| 系统 | 作用 | 来源 |
|------|------|------|
| **MetaQuery (Qwen3-VL)** | 从参考图像+文本中提取 256 个视觉语义 token | Meta 提出，基于 Qwen3-VL 多模态大模型 |
| **Wan2.2** | DiT 架构扩散视频生成模型 | 阿里巴巴 |

**核心原理**：MetaQuery 使用 Qwen3-VL 从参考图像 + 文本 prompt 中提取 **256 个视觉语义 token**（维度 4096），前置拼接到 Wan2.2 的 T5 文本编码上，作为所有 DiT 层 cross-attention 的 Key/Value，实现**零侵入式**视觉条件注入（无需修改 Wan2.2 模型内部结构）。

### 两条管线说明

| 管线 | Bridge 类 | 条件组合 | 用途 |
|------|----------|---------|------|
| **I2V (图生视频)** | `MetaQueryWanI2VBridge` | 首帧 VAE 编码 + MetaQuery 语义 + T5 文本 | 从首帧图像生成视频 |
| **Animate (人物动画)** | `MetaQueryWanAnimateBridge` | 参考图 VAE + CLIP + MetaQuery 语义 + 面部 Adapter | 人物动画视频生成 |

### I2V 管线条件注入方式

```
首帧图像 ──→ VAE encode → 20ch ──→ channel concat (与 noise latent 拼接为 36ch)
                                      ↓
            T5 文本编码 ──────┐      WanModel DiT
                              ├→ context concat → cross-attention
MetaQuery (Qwen3-VL) 参考图 ─┘
```

### Animate 管线条件注入方式（四重条件）

```
参考人物图
  ├─→ VAE encode → 20ch ──→ channel concat (结构条件)
  ├─→ CLIP ViT-H/14 → 257 token ──→ 独立 img cross-attn (全局视觉)
  └─→ MetaQuery (Qwen3-VL) → 256 token ──→ context concat (语义引导)

T5 文本 ──→ context concat (与 MetaQuery 拼接)

面部视频帧 ──→ motion_encoder → face_adapter ──→ 每 5 层交叉注意力 (面部条件)
```

## 7. 第五步：运行 I2V 管线（图生视频）

### 7.1 功能说明

I2V 管线接受一张**首帧图像**作为结构条件，加上**文本描述**和可选的 **MetaQuery 参考图像**（风格/语义引导），生成一段从首帧开始延展的视频。

**双重条件机制**：
1. **首帧条件** — 首帧图像经 VAE 编码为 20 通道 tensor，与噪声 latent 做 channel concat (36ch 输入)，提供**像素级结构一致性**
2. **MetaQuery 语义条件** — 参考图经 Qwen3-VL MetaQuery 编码为 256 个语义 token (4096 维)，前置拼接到 T5 文本 context，提供**高层语义引导**

### 7.2 配置入口脚本

编辑 `Wan2.2/demo_metaquery_i2v.py`，修改**用户配置区**：

```python
# ====== 用户配置区 (请修改为你的实际路径) ======

# Wan2.2 I2V 模型权重目录
WAN_CKPT_DIR = r"E:\models\Wan2.2-I2V-14B"

# MetaQuery + Qwen3-VL checkpoint 路径
METAQUERY_CKPT = r"E:\models\metaquery_qwen3vl_output"

# ── 首帧图像 (必须, I2V 的首帧条件) ──
FIRST_FRAME_IMAGE = r"E:\data\first_frame.jpg"

# ── MetaQuery 参考图像 (可选, 额外语义引导) ──
# 为空列表或 None 则默认使用首帧作为 MetaQuery 输入
MQ_REFERENCE_IMAGES = [
    # r"E:\data\style_reference.jpg",    # 可额外提供风格参考图
]

# 文本 prompt
PROMPT = (
    "Summer beach vacation style, a white cat wearing sunglasses sits on a "
    "surfboard. Crystal-clear waters and blue sky in the background."
)

# 视频生成参数
MAX_AREA = 720 * 1280           # 根据首帧宽高比自适应分辨率
FRAME_NUM = 81                  # 帧数 (必须为 4n+1 格式)
SAMPLING_STEPS = 40             # 去噪步数
GUIDE_SCALE = (3.5, 3.5)       # CFG (低噪声模型, 高噪声模型)
SHIFT = 5.0                    # 噪声调度 shift
SAMPLE_SOLVER = "unipc"        # "unipc" 或 "dpm++"
SEED = 42                      # 随机种子 (-1 = 随机)

# 显存优化
OFFLOAD_MODEL = True            # 不活跃模型卸载至 CPU (节省显存)
T5_CPU = False                  # T5 是否放 CPU (显存极其紧张时开启)
DEVICE_ID = 0                   # GPU 编号

# 输出
OUTPUT_DIR = "./outputs_i2v_demo"
FPS = 16
```

### 7.3 准备输入数据

| 输入项 | 要求 | 说明 |
|--------|------|------|
| **首帧图像** | RGB 格式，任意分辨率（脚本自动适配） | **必须提供**，作为视频的起始帧 |
| **MetaQuery 参考图** | RGB 格式，任意分辨率 | 可选，提供风格/内容参考。不提供则默认用首帧 |
| **文本 prompt** | 英文或中文描述 | 同时送入 T5 和 Qwen3-VL |

### 7.5 运行流程详解

脚本执行时会依次经历以下阶段：

```
[Step 1/3] 初始化 Wan2.2 I2V pipeline
    ├── 加载 WAN_CONFIGS["i2v-A14B"] 配置
    ├── 创建 WanI2V 实例
    ├── 加载 T5 文本编码器
    ├── 加载 VAE 编解码器
    └── 加载 DiT 高/低噪声模型

[Step 2/3] 初始化 MetaQuery + Wan2.2 I2V Bridge
    ├── 创建 MetaQueryWanI2VBridge 实例
    ├── 加载 MetaQuery checkpoint (Qwen3-VL backbone + Connector)
    │   ├── find_newest_checkpoint() 自动找到最新 checkpoint
    │   ├── MetaQuery.from_pretrained() 加载完整模型
    │   ├── 保留 MLLM backbone + Connector，删除 Sana Transformer (释放显存)
    │   └── 初始化 to_wan_proj 投影层 (connector_out_dim → 4096)
    ├── 验证 WanModel.text_embedding 输入维度 = 4096
    ├── 验证 WanModel.in_dim = 36 (16 noise + 20 condition)
    └── 设置 text_len 扩展: 512 → 768 (512 + 256 MetaQuery tokens)

[Step 3/3] 开始 MetaQuery I2V 视频生成
    ├── (a) 首帧编码
    │   ├── 首帧图像 → [-1, 1] 归一化
    │   ├── 根据宽高比 + max_area 计算 latent 尺寸
    │   ├── VAE 编码 → 16ch latent
    │   ├── 构建 mask (第1帧=1, 其余=0, 共4ch)
    │   └── concat(mask[4ch], latent[16ch]) → y[20ch]
    │
    ├── (b) T5 文本编码
    │   └── prompt → T5 Encoder → context [L_t5, 4096]
    │
    ├── (c) MetaQuery 编码
    │   ├── 参考图 + prompt → Qwen3-VL tokenize
    │   ├── Qwen3-VL 前向 → 提取 BOI/EOI 间的 256 个 MetaQuery hidden states
    │   ├── Connector (24层 Qwen2Encoder) 映射
    │   └── to_wan_proj 投影到 4096 维 → mq_context [256, 4096]
    │
    ├── (d) Context 拼接
    │   └── aug_context = cat([mq_context, t5_context]) → [256+L_t5, 4096]
    │
    ├── (e) 动态扩展 text_len
    │   └── WanModel.text_len: 512 → 768
    │
    ├── (f) 去噪循环 (CFG)
    │   ├── 每步执行两次前向:
    │   │   ├── 有条件: model(noise, t, y=y, context=aug_context)
    │   │   └── 无条件: model(noise, t, y=y_null, context=aug_context_null)
    │   └── 引导: pred = uncond + scale × (cond - uncond)
    │
    ├── (g) VAE 解码
    │   └── denoised latent → VAE decode → video [3, F, H, W]
    │
    └── (h) 恢复 text_len: 768 → 512 (在 finally 块中)
```

### 7.6 输出位置

| 生成视频 | `./outputs_i2v_demo/i2v_demo_YYYYMMDD_HHMMSS.mp4` | MP4, 16fps |

## 8. 第六步：运行 Animate 管线（人物动画）

### 8.1 功能说明

Animate 管线用于生成**人物动画视频**。通过四重条件注入：
1. **参考图条件** — VAE 编码参考人物图 (像素级人物外观)
2. **CLIP 视觉条件** — CLIP ViT-H/14 编码 (全局视觉语义)
3. **MetaQuery 语义条件** — Qwen3-VL MetaQuery (细粒度语义引导)
4. **面部条件** — 面部视频帧经 motion_encoder → face_adapter (面部表情/动作)

> **注意**：本版本**不使用骨架(pose)条件**，`pose_latents` 传入全零张量。

### 8.2 配置入口脚本

编辑 `Wan2.2/demo_metaquery_animate.py`，修改**用户配置区**：

# MetaQuery + Qwen3-VL checkpoint 路径

# 参考人物图（生成视频的主体参考）
REF_IMAGE_PATH = "/path/to/reference_person.png"

# 面部视频路径（512×512 裁剪的面部区域视频）
# 设为 None 则不使用面部条件

# MetaQuery 参考图像路径列表（额外语义引导，如风格参考）
# 设为 [] 或 None 则默认使用参考人物图
MQ_REFERENCE_IMAGE_PATHS = [
    # "/path/to/style_ref1.jpg",
]

# 文本提示词（Animate 默认使用配置文件中的 prompt）

# 输出目录
OUTPUT_DIR = "./outputs_metaquery_animate"

# 生成参数

CLIP_LEN = 77        # 每 clip 帧数 (4n+1)

```

```

    ├── 加载 WAN_CONFIGS["animate-14B"] 配置

    ├── 读取面部视频 (可选)
    └── 读取 MQ 参考图 (可选)

[4/4] 开始 MetaQuery 增强 Animate 生成
    ├── (a) T5 文本编码
    │
    ├── (b) MetaQuery 编码 (参考图 → 256 tokens)
    │
    ├── (c) 参考图 VAE 编码 → y[20ch]
    │
    ├── (d) 参考图 CLIP 编码 → img_emb[257 tokens]
    │
    ├── (e) 面部视频处理
    │   ├── motion_encoder 提取动作特征
    │   ├── face_encoder 提取面部特征
    │   └── face_adapter 准备交叉注意力注入
    │
    ├── (f) Context 拼接 + text_len 扩展
    │
    ├── (g) 去噪循环
    │   ├── 每步: 36ch input = [noise_16ch + y_20ch]

    │   ├── img cross-attn: CLIP img_emb
    │   └── face cross-attn: 每 5 层注入面部特征

    │

## 11. 常见问题排查

### Q1: `flash-attn` 安装失败

```bash
# 方案一: 无构建隔离安装
pip install flash-attn --no-build-isolation

# 方案二: 从 GitHub 源码安装
pip install git+https://github.com/Dao-AILab/flash-attention.git
```

### Q2: `ImportError: No module named 'trainer_utils'`

**原因**：`Qwen3-VL-main/metaquery-main/` 目录路径不正确或不存在。

`encoder.py` 通过以下方式定位 MetaQuery 源码：
```python
_MQ_ROOT = Path(__file__).resolve().parents[3] / "Qwen3-VL-main" / "metaquery-main"
```
其中 `parents[3]` 从 `Wan2.2/wan/metaquery/encoder.py` 向上 3 级到达 `Qwen3-VL/`，再拼接 `Qwen3-VL-main/metaquery-main/`。

**解决**：确保目录结构为：
```
Qwen3-VL/                             ← parents[3] 到达这里
├── Qwen3-VL-main/
│   └── metaquery-main/               ← 代码直接在此
│       ├── trainer_utils.py
│       └── models/metaquery.py
└── Wan2.2/wan/metaquery/encoder.py    ← 本文件
```

### Q3: `find_newest_checkpoint` 找不到 checkpoint

**原因**：MetaQuery checkpoint 路径下没有有效的 checkpoint 文件。

**解决**：确认路径下存在以下之一：
- `checkpoint-xxxxx/` 子目录（含 `model.safetensors` 或 `pytorch_model.bin`）
- 直接包含 `model.safetensors` 文件的目录

### Q4: 显存不足 (OOM)

```python
# 方案 1: 开启模型卸载 (已默认开启)
OFFLOAD_MODEL = True

# 方案 2: T5 放 CPU
T5_CPU = True

# 方案 3: 降低分辨率/帧数
FRAME_NUM = 49               # 减少帧数
MAX_AREA = 480 * 832          # 降低分辨率

# 方案 4: 使用更小的 Qwen3-VL (取决于 checkpoint)
# Qwen3-VL-2B → ~5GB
# Qwen3-VL-8B → ~16GB
```

### Q5: `frame_num` 和 `clip_len` 格式错误

Wan2.2 VAE 要求帧数为 **4n+1** 格式。合法值如：5, 9, 13, ..., 49, 77, 81, ...

```python
# 错误
FRAME_NUM = 80   # ✗ 不是 4n+1

# 正确
FRAME_NUM = 81   # ✓ (4×20+1)
FRAME_NUM = 77   # ✓ (4×19+1)
```

### Q6: `isinstance(guide_scale, float)` 类型错误

旧版代码中 `guide_scale` 传入 `int` 会导致报错。已修复为 `not isinstance(guide_scale, tuple)` 判断。如果遇到此问题，确保使用最新代码，或传入 `float` 类型：

```python
GUIDE_SCALE = 5.0       # ✓ float
# 或
GUIDE_SCALE = (3.5, 3.5)  # ✓ tuple (低/高噪声模型分别的 CFG)
```

### Q7: MetaQuery 是否真正起作用了？

观察控制台输出中的验证信息：
- `MQ cond vs uncond 余弦相似度` 应 < 0.99（表示有/无参考图编码出的特征不同）
- `cond-uncond 差异 L2` 应 >> 0（表示 CFG 有效）
- 可对比有/无参考图的生成结果来确认视觉引导效果

### Q8: 如何调整 MetaQuery 视觉引导强度？

通过 `MQ_GUIDANCE_SCALE` 参数控制：

| 值 | 效果 |
|----|------|
| 0.0 | MetaQuery 完全关闭，等同于纯文本条件 |
| 0.5 | 轻度视觉引导 |
| 1.0 (默认) | 与文本条件等权重 |
| 2.0 | 强视觉引导，参考图风格更突出 |
| 3.0+ | 极强视觉引导，可能过拟合参考图 |

### Q9: I2V 的首帧和 MetaQuery 参考图一定要相同吗？

不需要。I2V Bridge 支持分离的两种图像输入：
- `FIRST_FRAME_IMAGE` — 首帧图像，经 VAE 编码，提供结构条件（**必须提供**）
- `MQ_REFERENCE_IMAGES` — MetaQuery 参考图，提供语义条件（**可选**，不提供则自动使用首帧）

实际使用中可以用不同图像，例如首帧用实际场景图，MetaQuery 参考图用风格参考图。

### Q10: 支持哪些 Qwen3-VL 模型规格？

取决于 MetaQuery checkpoint 训练时使用的模型：

| 模型 | hidden_size | 显存占用 |
|------|------------|---------|
| Qwen3-VL-2B | 1536 | ~5GB |
| Qwen3-VL-4B | 2560 | ~10GB |
| Qwen3-VL-8B | 4096 | ~16GB |
